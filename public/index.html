LRU Cache

While studying data structures, I came across the LRU Cache and wanted to make my own implementation. It is a key-value store that performs in a way so that the most recently accessed items remain in the cache. Here, I noted some of my design decisions and considerations. Design We first create the underlying data structures for the LRU cache. The requirements for the cache: O(1) retrieval of values anywhere in the cache using a key. O(1) setting of values which include cache eviction. Memory should have a fixed size. Since we are going to use key to associate to a value, we opted to use std::unordered_map to ensure an average of O(1) lookup.
